## 三、首页划片下拉框过滤逻辑

在 `packages/api/src/chengdu_edu_api/routes/pages.py` 中添加了过滤函数：

```python
_SCOPE_KW = re.compile(r"[至界路街道巷大道区社区苑村]")
_SCOPE_NOISE = re.compile(r"招生|报名|年满|条件|政策|电脑随机|录取|简章")

def _is_dropdown_scope(text: str) -> bool:
    """判断是否为有效的划片范围文本（用于下拉框过滤）。"""
    if not text or len(text) < 8 or len(text) > 120:
        return False
    if _SCOPE_NOISE.search(text):
        return False
    return bool(_SCOPE_KW.search(text))
```

**过滤规则**：
- 文本为空或长度 < 8 → 排除
- 文本长度 > 120 → 排除（过长的通常是政策说明）
- 包含噪音关键词（招生/报名/年满/条件/政策/电脑随机/录取/简章） → 排除
- 不包含地理关键词（至/界/路/街/道/巷/大道/区/社区/苑/村） → 排除

**效果**：原来混入下拉框的"九年一贯制学校，小学部直升初中部"、"民办小学，面向成都市户籍适龄儿童招生"等非划片文本被过滤掉。

## 四、学校下拉框按区县分组实现

### 后端查询变更（pages.py）

```python
school_names_result = await session.execute(
    select(School.id, School.name, School.short_name, School.district_id, District.name.label("district_name"))
    .join(District, School.district_id == District.id)
    .order_by(District.name, School.name)
)
all_school_names = [
    {"id": row.id, "name": row.name, "short_name": row.short_name or row.name, "district_name": row.district_name}
    for row in school_names_result.all()
]
```

### 前端模板变更（index.html）

使用 Jinja2 `namespace` 跟踪当前区县名，自动插入 `<optgroup>` 标签：

```html
{% set ns = namespace(current_district='') %}
{% for school in all_school_names %}
  {% if school.district_name != ns.current_district %}
    {% if ns.current_district != '' %}</optgroup>{% endif %}
    <optgroup label="{{ school.district_name }}">
    {% set ns.current_district = school.district_name %}
  {% endif %}
  <option value="{{ school.name }}" ...>{{ school.name }}</option>
{% endfor %}
{% if ns.current_district != '' %}</optgroup>{% endif %}
```

**效果**：354所学校按区县分组展示（成华区、金牛区、锦江区、青羊区、天府新区、武侯区、高新区），用户可快速定位目标学校。

**HTMX行为保持不变**：`hx-trigger="submit, change from:select"` 仍然在选择时自动触发搜索。

## 五、verify_district_parity.py 加严后的规则说明

### 新增文件计数加载

`_load_file_counts()` 函数从文件系统读取：
- `file_schools`：区域 `schools.yaml` 中的学校总数
- `file_scopes`：`mapping_scraped.json` 中有效划片数（长度>=8且含地理关键词）

### 7条加严验证规则

| 编号 | 规则 | 说明 |
|------|------|------|
| 1 | DB学校数 vs 文件学校数 | 差异不超过±2 |
| 2 | DB已映射 >= 文件划片数×80% | 防止mapped远少于文件数据 |
| 3 | DB划片总数 >= MIN_SCOPES | 保持原阈值 |
| 4 | enrollment >= DB学校数×80% | 确保入学信息覆盖率 |
| 5 | intel_mapping >= 1 | 必须有情报源记录 |
| 6 | gov_policy >= 1 | 必须有政策文件 |
| 7 | mapped/total >= 90% | **新增**：高新5/41这种情况会直接FAIL |

### 输出格式

```
{区县}: PASS | schools(file=X/db=Y) scopes(file=A/mapped=B/C) enroll=D intel_map=E intel_mirror=F gov=G
```

**示例**：
```
gaoxin: PASS | schools(file=43/db=43) scopes(file=40/mapped=41/41) enroll=43 intel_map=3 intel_mirror=0 gov=1
```

含义：文件43所学校=DB 43所；文件40条有效划片，DB已映射41条/总41条；入学信息43条；情报源3条。

**如果高新出现 mapped=5/total=41 的情况，规则7会触发FAIL**（5/41 = 12.2% < 90%）。
